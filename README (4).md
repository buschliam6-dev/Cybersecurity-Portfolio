Projects

1. Python Multi-Factor Authentication (MFA)

A Python-based project demonstrating a multi-factor authentication process.

The project includes:

- Password verification using SHA-256 hashing.
- Time-based One-Time Password (TOTP) generation and verification.
- Simulated biometric verification using hash comparison.
- Access is granted only when all three authentication factors pass.

Key skills: Python, authentication, hashing, TOTP, and security fundamentals.

2. Caesar Cipher Encryption

A Python project demonstrating the Caesar cipher, a basic encryption technique that shifts letters in the alphabet to encode and decode messages.

Key skills: Python, encryption, decryption, algorithms, and basic cryptography.

3. Basic Pentesting 1

A practical penetration-testing exercise involving the investigation and exploitation of a vulnerable Linux environment.

The project covers:

- Network discovery and reconnaissance.
- Port scanning and service enumeration using Nmap.
- Research into a potentially vulnerable ProFTPD service.
- Exploitation using Metasploit.
- Password hash extraction and password-cracking exercises using John the Ripper.
- Verification of access to the target system.

Key skills: Linux, networking, Nmap, Metasploit, enumeration, and password auditing.
